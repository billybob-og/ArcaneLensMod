# Soul Pedestal

![](@arcanelens:soul_pedestal)

Burns soul sand and items to generate mana, which it feeds to any [Lens Pedestal](@arcanelens:lens_pedestal) linked to it. Lights up while active.

## Linking

Link it to a nearby Lens Pedestal to start charging lenses placed there. A [Soul Feeder](@arcanelens:soul_feeder) can be linked to a Soul Pedestal to keep it fed automatically.

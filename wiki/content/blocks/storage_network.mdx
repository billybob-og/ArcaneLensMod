# Networked Storage

A shared, searchable item storage system unlocked via the Storage System Skill Tree node.

## Living Chest

A 5-slot storage cube. Any Living Chest placed touching another automatically merges into one shared pool.

<ProjectRecipe id="arcanelens:storage_block"/>

## Storage Connector

Bridges two otherwise-separate Living Chest clusters into a single network, without adding any storage of its own.

<ProjectRecipe id="arcanelens:storage_connector"/>

## Living Terminal

Browses an entire connected cluster as one scrollable grid, with a search box and a sort button (Default / Name / Count). Holds [Compactor and Slot Upgrades](@arcanelens:upgrades) to raise per-item stack size or add bonus pool slots. Once bound to a [Warped Anchor](@arcanelens:warped_anchor), its storage can be opened from anywhere.
